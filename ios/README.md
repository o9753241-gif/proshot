# iOS-клиент ProShot

Нативный SwiftUI. Файл `.xcodeproj` в репозитории не хранится — он собирается
из `project.yml`, чтобы не ловить конфликты слияния в `project.pbxproj`.

## Открыть на Mac

```
brew install xcodegen
cd ios && xcodegen generate && open ProShot.xcodeproj
```

## Что уже написано

```
ProShot/Config.swift              адрес бэкенда и идентификаторы товаров
ProShot/Data/DeviceID.swift       identifierForVendor для X-Device-Id
ProShot/Data/APIModels.swift      модели по app/schemas.py сервера
ProShot/Data/ProShotAPI.swift     клиент: авторизация, пакеты, сцены, покупка, генерация
ProShot/Store/PurchaseManager.swift   StoreKit 2
ProShot/Data/PhotoPicker.swift        выбор фото и сохранение результата
ProShot/App/                          точка входа, состояние, навигация, общая обвязка
ProShot/Screens/                      восемь экранов
ProShot/Resources/*.lproj             тексты, перенесённые из Android без изменений
Products.storekit                     товары для отладки покупок без App Store Connect
```

### Экраны

Те же восемь маршрутов, что в `Routes.kt`: онбординг, каталог, пакеты, выбор
сцен, сводка, загрузка фото, результат, галерея. `PaymentScreen` и `StyleScreen`
из Android-версии не переносились — там они пустые заглушки.

### Тексты

Все строки перенесены из `app/src/main/res/values*/strings.xml` скриптом, без
переписывания: 105 ключей на шести языках плюс английский как запасной.
Формат подстановок приведён к iOS (`%s` → `%@`), остальное не тронуто.

### Файл товаров для отладки

`Products.storekit` лежит рядом с проектом, а не внутри цели: иначе он попал бы
в бандл приложения. В Xcode он выбирается в схеме — Run → Options → StoreKit
Configuration. С ним покупки работают на симуляторе без App Store Connect.

## Чего этот код ещё не проходил

**Компиляции.** Swift собирается только на macOS, поэтому до аренды Mac всё
написанное проверено вычиткой, а не сборкой. Первый запуск `xcodegen generate`
и сборка почти наверняка дадут список мелких правок — это ожидаемо.

Что проверить удалось без компилятора: все 73 ключа локализации, которые
дёргает код, существуют, и число подстановок в каждом формате совпадает с
числом переданных аргументов — то есть падений `String(format:)` быть не должно.

## Порядок при покупке

Он такой же, как в Android-версии, и менять его нельзя:

1. Apple проводит оплату и отдаёт подписанную транзакцию.
2. Транзакция уходит на наш сервер, тот проверяет подпись и начисляет фото.
3. И только потом `transaction.finish()`.

Если закрыть транзакцию до ответа сервера и в этот момент пропадёт связь,
деньги спишутся, а фото не начислятся, и восстановить будет нечем.

`Transaction.updates` слушается с запуска приложения, а не с экрана покупки:
транзакция может прийти после перезапуска.

## Открытые решения

- **Минимальная версия iOS.** Стоит 17.0. StoreKit 2 требует 15.0, так что
  можно опустить — одна строка в `project.yml`.
- **Только iPhone.** Поддержка iPad потребует отдельных макетов и скриншотов.
